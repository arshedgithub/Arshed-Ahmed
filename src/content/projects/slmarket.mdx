## Architecture

The ecosystem is two independent applications. The marketplace is a Next.js and TypeScript app on PostgreSQL (through Prisma), with Redis for caching and Cloudinary for media, deployed on Vercel. SLMarket Flow is a Laravel, Vue.js and Inertia.js app on MySQL, deployed on cPanel. Both ship through GitHub Actions. {/* TODO: confirm: do the two products share accounts or data? ## Key technical decisions

{/* TODO: confirm: the decisions come from the CV; the reasons given for them are my draft. */}

- **Two stacks, one job each.** The marketplace is a public, SEO-sensitive Next.js app on Vercel; Flow is an authenticated back-office tool where Laravel and Inertia.js keep forms and CRUD screens fast to build.
- **TypeScript and Prisma** on the marketplace for type safety from the database schema to the UI.
- **PostgreSQL with an optimised relational schema** for listings, sellers and orders, and **Redis caching** on hot paths.
- **Authentication and role-based authorisation** on both products, with end-to-end order workflows.
- **Locale-based routing and content translation** for a multi-language audience.
- **Unit and integration tests** on core marketplace flows, run by **GitHub Actions** before every release.
