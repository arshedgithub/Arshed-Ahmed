## Architecture

Customers message a WhatsApp number connected through Twilio. Twilio forwards each message to a Python webhook service, which uses an LLM API to understand the message and write a reply, then sends the reply back through Twilio. {/* TODO: confirm: where orders and conversation state are stored. */}
